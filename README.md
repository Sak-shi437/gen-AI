# 🤗 Hugging Face

**Hugging Face** is an open-source AI/ML platform and ecosystem that provides **pre-trained models, datasets, and tools** for building and using machine learning and Generative AI applications.

### Basic Flow

```text
Dataset
   ↓
Pre-trained Model
   ↓
Tokenizer
   ↓
Token IDs
   ↓
Inference
   ↓
Output
```

**Fine-tuning** can be added when a pre-trained model needs to be adapted to a specific task.
